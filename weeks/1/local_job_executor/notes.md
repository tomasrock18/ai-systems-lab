## Заметка 1

Если я правильно понял, от меня требуется реализовать класс, в который можно с помощью менеджера контекста, закидывать
асинхронные функции и собственно ожидать их выполнения.

Честно говря такое даже не использовал, но вот что интересно: как ведёт себя threadpoolexecutor если сначала задать n
задач, а после сделать какой-нибудь вывод.

Интересно, этот код показывает что вывод после контекста появляется после заверщения всех workers:

```python
import concurrent.futures
import time


def job(tts: float) -> None:
    time.sleep(tts)
    print(f"I wake after {tts} secs")


def main() -> None:
    with concurrent.futures.ThreadPoolExecutor(max_workers=10) as executor:
        for i in range(1, 5):
            executor.submit(job, i)

    print("All jos running")


if __name__ == "__main__":
    main()

```

Значит сделаю так же, контекст, в который летят асинхронные функции. Отдельный поток/процесс делать особого смысла нет,
по аналогии с кодом выше, так что задача в некотором смысле упрощается.
